## 🚀 CONFIGURACIÓN RÁPIDA

### 1. Requisitos
- PHP 8.1+
- MySQL 8.0+
- Composer

### 2. Instalación
```bash
cd sistema
composer install
cp .env.example .env
php artisan key:generate
```

### 3. Base de Datos
```bash
mysql -u root -p salvietti_db < database/salvietti.sql
```

### 4. Iniciar
```bash
php artisan serve
```

### 5. Acceder
```
http://localhost:8000
```
